➛ How to Install and implement:
1. Download the package from the GitHub repo (duh!!) through a UnityPackage or the entire thing. (I recommend the UnityPackage)
2. Move the package/folders into your assets folder, if it’s outside it will not work.
3. To be sure you have everything, you should have 3 folders containing Plugins, Prefabs, and Scripts
4. In the Prefabs folder drag and drop the “++ Steam Integration” GameObject into your scene. 
5. Go to the scripts folder and open the SteamIntegration.cs file
6. In the Start() method insert your App ID inside this line of code: Steamworks.SteamClient.Init(0000000), very important
7. You’re done!


➛ Other Features of SteamIntegration.cs:
* There are 2 simple methods you can use in this script, but this script should mainly just handle the simple integration of Steamworks in your app
* GetSteamName() => returns the Steam name (not username)
* GetPlayerSteamID() => returns the Steam player’s ID (ex: STEAM_0:1:12345678)








➛ How to unlock/clear/check achievements:
1. Both scripts follow a singleton pattern and has a static instance to easily access
2. Inside the AchievementManager.cs file is a static class called AchievementIDs. I recommend using it to keep an organized list of all your achievements and their IDs. 
3. Lastly call on AchievementManager.cs with the public methods such as 
   1. UnlockAchievement(string achievementId)
   2. ClearAchievement((string achievementId)
   3. AchievementStatus((string achievementId)
